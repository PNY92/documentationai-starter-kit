## New features

**Windows x64 executable packages** — Zeta is now available as a downloadable Windows x64 ZIP package. You no longer need to build from source or install the .NET SDK, Godot, or a database server.

- Download the ZIP, extract the complete folder, and run `Zeta.exe`.
- The package bundles the .NET runtime, SQLite, and all Godot resources — no additional setup required.
- Packages are published as GitHub prereleases when a version tag is pushed.

See the [Quickstart](quickstart) guide for getting started.

</Update>
